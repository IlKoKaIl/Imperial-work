# Instrumentation Exam Revision Plan (Exam: May 14)

Goal: strong pass from a weak starting point.

Default day shape:

- 45-60 min: read/condense the day's topic.
- 2-2.5 h: attempt questions without solutions.
- 45-60 min: mark, correct, and log mistakes.
- 30-45 min: recall formulas/methods from memory.

Rules:

- Problem solving beats rereading.
- Use solutions only after a serious attempt.
- Every missed question creates one error-log entry.
- Missing notes should be compact and exam-useful, not pretty.

## Revised Triage Strategy

Trying to finish every problem sheet question is no longer the best use of time. Use the problem sheets as method training, then switch to past papers earlier.

Priority order:

- Do seminar questions first where they exist.
- Add only high-yield non-seminar questions that repeat in past papers.
- If a question takes too long, read the solution, write the method in the error log, and move on.
- Past papers are now the main exam-representation source.

## Past Paper Handling

When past papers are added:

- Put them in a clear folder, e.g. `Instrumentation/Course notes/Past papers`.
- Split into `with solutions` and `without solutions`.
- Do the two with solutions first.
- For unsolved papers, attempt timed first, then build solutions using course notes and problem sheet solution patterns.
- Prioritize recent papers and repeated question types.
