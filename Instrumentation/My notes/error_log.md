# Instrumentation Error Log

Every mistake gets one entry. Keep entries short and practical.

Template:

| Date | Source | Topic | What went wrong | Correct method | Retry question |
|---|---|---|---|---|---|
| | | | | | |

## Common Mistake Categories

- Units: forgot conversion, e.g. `kHz`, `uF`, `nT`, `fT`, `dB`.
- Sign convention: op-amp inversion, feedback signs, pole signs.
- Domain confusion: time domain vs frequency domain vs `s` domain.
- Formula recall: knew concept but not equation.
- Algebra: partial fractions, logs, exponentials.
- Interpretation: could calculate but not explain physically.

## High-Value Redo Rule

For each logged mistake:

- Redo the original question after 24 hours.
- Write the key method in one sentence.
- Do one similar question if available.
