# Closed-Book Recall Prompts

Use for the first 20 minutes of each session. Write answers on blank paper, then check the recall sheets or notes.

## Frequentist Prompts

1. Write the mean and variance of Bernoulli, binomial, Poisson, Gaussian, exponential, and Rayleigh distributions.
2. Derive the binomial estimator for $p$ using method of moments.
3. Derive the Poisson MLE for one count and for repeated counts.
4. Derive the exponential MLE for $\lambda$ and for lifetime $\tau$.
5. Write the Gaussian likelihood for independent data and derive $\hat{\mu}$ and $\hat{\sigma}$.
6. Write the normal equations for fitting $y=a_0+a_1x+a_2x^2$ with known Gaussian error.
7. Define bias, consistency, efficiency, and minimum variance.
8. Explain why a nonlinear transform of an unbiased estimator can become biased.
9. Define Type I error, Type II error, significance, and power.
10. Write the steps of a Neyman construction with a likelihood-ratio statistic.
11. State Wilks' theorem and when it gives a chi-square threshold.
12. Describe a goodness-of-fit test using a saturated model.

## Bayesian Prompts

1. Derive Bayes theorem from product rules.
2. Name likelihood, prior, posterior, and evidence in $p(\theta \mid d)$.
3. Explain likelihood vs sampling distribution in one sentence.
4. Given a binomial likelihood and Beta prior, write the posterior update.
5. Watch the exponent convention: Beta prior can be written as $q^{a-1}(1-q)^{b-1}$ or $q^x(1-q)^y$.
6. For a posterior, write how to find MAP, posterior mean, and curvature variance.
7. Explain why evidence requires a proper prior.
8. Derive posterior odds and state when they equal the Bayes factor.
9. Describe Occam penalty in evidence/model comparison.
10. Write the sequential updating identity for two datasets.
11. Define latent variables and write a hierarchical posterior with marginalisation.
12. Describe ABC/SBI and the role of data compression.
