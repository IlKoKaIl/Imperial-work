# Guided Warm-Up Prompts

Use these while memory is still rusty. You may keep the relevant recall sheet open for the first 5 minutes, then close it and write what you can.

## Frequentist Warm-Up

1. Copy the distribution table from `recall-sheet-frequentist.md`, then close it and rewrite it from memory.
2. For one distribution, write: support, PDF/PMF, mean, variance, and one likely estimator.
3. Write the generic MLE workflow in five lines.
4. Write one example of method of moments.
5. Write the definitions of bias, consistency, Type I error, Type II error, and power.
6. Write the Neyman construction as numbered steps.

## Bayesian Warm-Up

1. Copy Bayes theorem once, then close the sheet and rewrite it with term names.
2. Write the difference between likelihood and sampling distribution.
3. Write the beta-binomial update in both exponent conventions.
4. Write the MAP workflow: posterior, log, derivative, solve.
5. Write the evidence integral and posterior odds equation.
6. Write the ABC/SBI algorithm in six lines.

## Rule

The warm-up is not the study session. Stop after 20 minutes and move into worked examples.
