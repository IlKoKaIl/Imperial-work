## Redo Rules

- If you needed the solution, mark `redo`.
- Redo after 48 hours.
- Redo again after 7 days if the pattern still feels shaky.

## What To Say In Interviews

For every coding problem:

1. Restate the problem.
2. Ask about edge cases if needed.
3. Give brute force first if useful.
4. Explain the improved approach.
5. State time and space complexity.
6. Code cleanly.
7. Test on one normal case and one edge case.
